# 🕌 The Life Muslim

## 🛠️ Getting Started
<img src="screenshots/mockup.jpg">
**The Life Muslim** is a modern Islamic lifestyle app built with Flutter. It aims to provide essential tools for every
Muslim in their daily life – including prayer times, Qibla direction, Quran reading, and more – all in one clean and
intuitive interface.

## ✨ Features

- 🕋 Accurate Prayer Times based on your location
- 🧭 Qibla Direction with compass support
- 📖 Full Quran with Surah and Juz navigation
- 📖 Some important Azkars
- 🔖 Bookmark Ayahs for later reference
- 📍 Location-based services using GPS
- 🌙 Beautiful and simple UI with dark/light modes
- 📿 Tasbeeh every day with save last count
